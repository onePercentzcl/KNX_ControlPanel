# Implementation Plan: KNX 智能面板系统

## Overview

本实施计划将 KNX 智能面板系统（成品1 按键面板 / 成品2 机械棘轮旋钮屏面板 / 成品3 SmartKnob 可调阻尼旋钮面板）的设计转化为可由编码代理逐步执行的原子任务序列。每个任务控制在 0.5–1.0 小时粒度，确保增量可验证、无悬空代码。

**实现语言**：固件统一使用 **C/C++**（RP2040 基于 arduino-pico 框架，ESP32-S3 基于 ESP-IDF / Arduino 框架）；纯逻辑层抽离为可在 PC 上独立编译的 host C/C++ 模块，使用 **rapidcheck** 进行属性测试；上位机脚本使用 Python（knxd / xknx / 压测）。

**阶段与工时**：核心工作 105 天、570 工时，另加 10 天分阶段缓冲，日历总跨度 115 天（2026-10-29 – 2027-02-20）。缓冲用于吸收投板/长交期件等料、烤机与上墙期不可控延误（原 R-009 零裕量风险的缓解措施）。每个缓冲块位于阶段末，不占工时；若阶段提前完成，缓冲顺延给下一阶段。五个阶段如下（日期已含缓冲后顺移）：

| 阶段 | 工作天 | 缓冲 | 日期区间（含缓冲） | 工时 | 主题 |
| :--- | :--- | :---: | :--- | :---: | :--- |
| Phase 1 | Day 1–6 | +1 | 2026-10-29 – 11-04 | 34h | 环境方案设计 / 下单 / 搭建调试 + 三款面板验证方案设计与验证物资下单 |
| Phase 2 | Day 8–15 | +2 | 2026-11-05 – 11-14 | 42h | 验证门①② 执行 + 成品1/2 原型设计与投板 + 批次2/3 下单 |
| Phase 3 | Day 18–49 | +3 | 2026-11-15 – 12-19 | 172h | 成品1/2/3 固件-装配-交付 + 验证门③ + 四层板投板 + 三机交响 |
| Phase 4 | Day 53–78 | +2 | 2026-12-20 – 2027-01-16 | 146h | 手感克隆 / 恒温联动 / ESD / ID 家族化 / 72h 烤机 / 备份机复刻 / 上墙与上墙期优化 |
| Phase 5 | Day 81–113 | +2 | 2027-01-17 – 02-20 | 176h | 工程手册 / 4K 大片 / 开源发布 / 离线包 / 满月体检 / 百项验收 / 收官移交 |

> **缓冲使用规则**：缓冲是"时间裕量"，不是额外任务。阶段的全部任务按时完成即进入缓冲，缓冲未用完的天数累加给后续阶段（滚动缓冲）；任何一阶段吃光自己的缓冲仍延期，则动用后续阶段的缓冲并在检查点告警。10 天缓冲集中分配在投板等料最密集的 Phase 2/3（共 +5 天）。

**任务约定**：
- 标 `*` 的子任务为测试类任务（单元/属性/集成测试），可跳过以加速 MVP；顶层任务不标 `*`。
- 每个任务标注预计工时（0.5 或 1.0h）与依赖任务 ID。
- 属性测试任务显式引用设计文档《Correctness Properties》中的属性编号与需求条款。
- 检查点任务用于阶段性验证："确保所有测试通过，如有疑问询问用户。"
